# Ecmel’in Merak Kutusu

Ecmel’in doğada fark ettiği şeyleri ailesiyle keşfettiği Türkçe animasyon serisi. Bölümler küçük bir gözlemle başlar ve bilimsel cevabı çizgi film içinde gösterir.

Mac’te çalışan n8n akışları, Magic Hour üretim planı, FFmpeg kurgusu ve YouTube bağlantı adımları [otomasyon rehberinde](automation/README.md). İlk kurulumdan sonra `plan` modunda, kredi harcamadan bölümün süre ve maliyetini görebilirsin.
